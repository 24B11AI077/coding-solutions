# LPYAS59

![Difficulty](https://img.shields.io/badge/Difficulty-Medium-yellow)

## Problem

Write a program to check whether a number given as user input is positive, negative, or zero.

### Sample 1:
Input
Output

```
20
```

```
Positive
```

### Sample 2:
Input
Output

```
0
```

```
Zero
```

### Sample 3:
Input
Output

```
-95
```

```
Negative
```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-01T15:20:30.834Z  

```py
# cook your dish here
val = int(input())
if val > 0 :
    print("Positive")
elif val == 0:
    print("Zero")
else :
    print("Negative")
```
